# 构建说明

[返回 README](../README.md) · [English README](../README.en.md)

以下命令在 Windows PowerShell 中执行，工作目录为仓库根目录。

## 依赖与路径

- Windows x64。
- CMake 3.20 或更高版本。
- Qt 6.2.4，包含 Core、Widgets，使用 MinGW 版本。
- Qt 配套的 MinGW 11.2.0 x64，包含 `g++`、`mingw32-make`、`windres`。

当前 [CMakeLists.txt](../BuildTest/CMakeLists.txt) 使用作者本机的绝对路径。
安装位置不同时，先修改其中对应的路径：

| 配置位置 | 当前路径 |
|---|---|
| 动态 Qt 与 `windeployqt.exe` | `D:/qt/6.2.4/mingw_64` |
| MinGW 编译器与运行库复制目录 | `D:/qt/Tools/mingw1120_64/bin` |
| 静态 Qt 与插件库（仅静态构建需要） | `D:/qt/6.2.4-static-mingw` |

这些路径由脚本直接设置，单独传入 `-DCMAKE_PREFIX_PATH` 不会覆盖它们。
将对应 MinGW 的 `bin` 目录放到当前终端 PATH 首位，并确认工具可用：

```powershell
$env:PATH = "D:\qt\Tools\mingw1120_64\bin;$env:PATH"
cmake --version
g++ --version
```

## 构建与运行

首次构建可使用动态 Qt：

```powershell
cmake -S BuildTest -B BuildTest/build/dynamic -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DUSE_STATIC_QT=OFF
cmake --build BuildTest/build/dynamic --parallel
& '.\BuildTest\bin\SFC\SimpleFilesCompressorGUI.exe'
```

产物位于 `BuildTest/bin/SFC/`。动态构建会在构建后部署 Qt 与 MinGW 运行库，
分发时保留整个目录。

项目默认启用静态 Qt，需要先准备与该 MinGW 工具链匹配的 Qt 6.2.4 静态库及插件，
并按上表调整路径，然后执行：

```powershell
cmake -S BuildTest -B BuildTest/build/static -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DUSE_STATIC_QT=ON
cmake --build BuildTest/build/static --parallel
```

静态构建的可执行文件也输出到 `BuildTest/bin/SFC/`。
更换工具链或生成器时使用新的构建目录，避免复用旧的 CMake 缓存。

## 测试

测试使用独立 CMake 工程，无需 Qt；继续使用上述 MinGW 环境：

```powershell
cmake -S BuildTest/tests -B BuildTest/tests/build -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=g++
cmake --build BuildTest/tests/build --parallel
ctest --test-dir BuildTest/tests/build --output-on-failure
```

测试包括单元测试和归档往返验证；失败时查看 CTest 输出中的具体用例。

# Simple Files Compressor (SFC) 开发日志

> 本日志根据 Git 提交历史和项目文档整理。日期按提交日期倒序排列；同一天的多个提交合并为一条记录，纯合并、备份和重复提交不重复展开。

## 开发记录

### 2026-09-03

- 修复 AES 模块三处缺陷：providers 数组越界（2 个元素循环上界 3）、从未赋值的死成员 `aesKey`、`AesEncryption` 中的无效 `resize`；行为不变，属正确性清障。
- 新增独立单元测试工程（MinGW、无 Qt）：test_aes 覆盖 round-trip、IV 随机性、异常路径等 186 项，全部通过。
- 删除死代码：heffman 五个 Worker（旧线程池在模块层的全部使用者，零实例化）、`Schedule/`、`DataBlocks/`、旧 `ThreadPool/` 六文件；`sfc::block_t` 别名随 DataBlocks 退役收敛到 `Heffman_type.h`。
- 新增 `BufferPool/`：acquire 空池阻塞（背压）、release 只清长度保留容量、close 收尾唤醒；test_bufferpool 22 项单测通过，暂未接入主流程。
- 仓库结构重组：`Y_Manager_GUI/` 只保留纯代码；构建与测试独立为根目录 `BuildTest/`（CMakeLists + build + bin + tests）；非代码资产归并 `DevFiles/`；用户指南回到仓库根；清理失效构建缓存（搬家前 TempDocx 时代的 NMake/MSVC 缓存）并取消跟踪 `.zcode/`。
- 新增《线程池调研与改造计划.md》：v1 问题清单（析构 join 挂死、专有队列负载不均、异常即崩）、v2 设计（共享队列 + future + WorkerEnv）、并发不安全模块调研结论（全部为"可变成员状态"类，无算法级不安全，per-thread 实例可消除）、流水线接线形态与验收清单。
- 修复策划文档编码（GBK → UTF-8），与描述已退役模块的 Instructions.md 一并归档至 `DevFiles/DocsArchive/` 并标注非主要文档。
- Release 静态 Qt 全量构建通过，产物 `BuildTest/bin/SFC/SimpleFilesCompressorGUI.exe`。

**阶段结果**：纠错与结构清障完成，主循环保持串行、输出格式不变；线程池 v2 与流水线并行的施工图就绪，转入作者自行实现阶段。

# 界面设计

文档 ID：`GUI-DESIGN`  
状态：`Active`  
维护计数：`0/5`  
最后更新：`2026-10-26`

## 1. 适用范围

本篇规定 `SimpleFilesCompressorGUI.exe` 的窗口结构、跨线程信号链、模式状态机与窗口关闭时的线程安全，覆盖 `SFC_GUI/` 的入口、窗口与工作类。逐控件的属性取值、归档写入与压缩内核行为不在本篇范围。

## 2. 文件职责

| 文件 | 职责 |
|---|---|
| `SFC_GUI/src/MainWindow.cpp` | 窗口骨架与两页 `QTabWidget`、背景绘制、拖放入口、析构顺序，以及把工作类固定文案映射为译文 |
| `SFC_GUI/src/MainWindow_Compression.cpp` | 压缩页控件构建、压缩任务启动、进度槽与结束槽 |
| `SFC_GUI/src/MainWindow_Decompression.cpp` | 解压页控件构建、解压任务启动、进度槽与结束槽 |

两页共用 `MainWindow.h` 的控件指针与 `m_isProcessing`，模式状态机由该标志单向驱动。

## 3. 窗口结构

- 中央部件一个 `QVBoxLayout`，内放 `m_tabWidget`；第 0 页压缩、第 1 页解压（`SFC_GUI/src/MainWindow.cpp:86-87`）。
- 每页一个 `QHBoxLayout`，左右两栏拉伸比 3:2（`SFC_GUI/src/MainWindow_Compression.cpp:351-354`）。
- 左栏是输入与输出设置，右栏是进度区与起始按钮（`SFC_GUI/src/MainWindow_Decompression.cpp:129-240`）；压缩页右栏另含模式选择（`SFC_GUI/src/MainWindow_Compression.cpp:158-243`）。进度区含当前文件标签、进度条、百分比标签、只读日志框。
- 窗口无菜单栏与工具栏，入口只有页内按钮与拖放。
- 背景取自 `:/images/background.jpg`，按窗口比例等比放大后居中裁剪写入 `QPalette::Window`，`resizeEvent` 中重算（`SFC_GUI/src/MainWindow.cpp:167-211`）。

## 4. 工作线程生命周期

1. 起始槽内 `new QThread` 与 `new CompressionWorker`，两者都不带 parent（`SFC_GUI/src/MainWindow_Compression.cpp:473-474`）。
2. 在 `moveToThread` 之前调用 `setCompressionParams()` 或 `setDecompressionParams()` 写入参数（`:475`）。
3. `m_worker->moveToThread(m_workerThread)`（`:476`）。
4. 连接 `QThread::started` 到 `doCompression` 或 `doDecompression`，连接 `detailedProgress`、`finished` 到 `MainWindow` 槽（`:478-480`）。
5. `m_workerThread->start()`（`:482`）。

任务运行期间，界面侧对工作对象的唯一调用是 `requestStop()`，它只写 `std::atomic<bool>`（`SFC_GUI/src/CompressionWorker.h:67`）。工作线程退出后，由界面线程删除线程与工作对象，见 §5 与 §11。

## 5. 跨线程信号链

工作对象在第 3 步之后归工作线程所有，两条信号到 `MainWindow` 槽的连接由 `Qt::AutoConnection` 解析为队列连接。

| 链路 | 信号与参数类型 | 节流与界面动作 |
|---|---|---|
| 进度 | `detailedProgress(const QString &filename, double fileProgress, double overallProgress, const QString &status)` | 发端满足 200 ms、2 个百分点、进度达 100% 三者之一才发（`PROGRESS_INTERVAL_MS`、`PROGRESS_DELTA`）；收端写进度条与两个标签 |
| 日志 | 复用 `detailedProgress`，没有独立日志信号 | 每个放行事件在槽内 `append` 一行；日志文档行数超过 500 时按选区裁剪（`SFC_GUI/src/MainWindow_Compression.cpp:497-504`） |
| 完成与失败 | `finished(bool success, const QString &message)` | 每次任务恰好发一次；收端恢复控件、写日志与结果框，再 `quit()`/`wait()`/`delete` 线程与工作对象 |

`overallProgress` 是任务刻度：压缩把主循环 0~100 线性映射到 20~95（`SFC_GUI/src/CompressionWorker.cpp:238`），解压映射到 15~95（`:398`）；阶段切换的定点值（压缩 0/5/10/15/20，解压 0/5/8/10/15）不经节流直接发出。`fileProgress` 保持单文件 0~100 原值。

## 6. 取消链路

1. `MainWindow` 析构调用 `m_worker->requestStop()` 置位标记（`SFC_GUI/src/MainWindow.cpp:24`）；界面没有取消按钮。
2. 任务在阶段间隙检查 `isStopRequested()`，命中即发 `finished(false, ...)` 并返回（`SFC_GUI/src/CompressionWorker.cpp:166-222`）。
3. 主循环内命中时，进度回调抛 `std::runtime_error("Operation cancelled by user")` 展开循环，外层按该约定文本改写为取消结果（`:231-235`、`:271-274`）。

取消与失败共用 `finished(false, ...)`，界面走失败路径：日志记失败行，消息框展示未翻译的英文取消文案。`localizeWorkerDialogMessage()` 按前缀匹配已知文案，取消消息原样返回（`SFC_GUI/src/MainWindow.cpp:244-330`）。

## 7. 模式与控件状态

解压不选模式，`doDecompression()` 从归档头的 `strategy` 字段复原（`SFC_GUI/src/CompressionWorker.cpp:358`）。

| 控件 | 压缩页 | 解压页 |
|---|---|---|
| 起始按钮 | `Start Compression` | `Start Decompression` |
| 模式下拉 | HuffmanOnly、HuffmanAES、AESOnly、PackOnly，默认第 0 项，`currentData()` 存 `Y_flib::CompressionMode` 整型值（`SFC_GUI/src/MainWindow_Compression.cpp:177-189`） | 无该控件 |
| 口令输入 | `hasEncryption(mode)` 为真时可用，否则禁用并换提示文案 | 始终可用 |
| 归档路径 | 无 | 后缀必须是 `.sy`，否则弹出警告并中止 |
| 输入列表 | 多项列表，可增、删、清空 | 无列表，`Reset` 清空四个输入框 |
| 进度与日志 | 一套进度条、标签、日志框 | 另一套同构控件 |

处理中 `m_isProcessing` 为真：两页起始按钮禁用，当前页按钮文案改为 `Processing...`，另一页 `setTabEnabled(false)`；压缩启动时另禁模式下拉。处理结束在 `finished` 槽统一复位。

## 8. 布局与样式

界面全部由 `createCompressionTab()`、`createDecompressionTab()` 以布局代码搭建，仓库内无 `.ui` 与 `.qss` 文件。样式表是逐控件的内联 `setStyleSheet` 字符串，同类控件在各 cpp 内用局部 `btnStyle`、`groupBoxStyle` 串复用。行内提示文本由 `PlaceholderLineEdit::paintEvent` 自绘 ghost text，默认色 `QColor(178, 186, 196)`，字号比正文小 1 pt（`SFC_GUI/src/PlaceholderLineEdit.h:31-66`）。

## 9. 拖放与目录

`dragEnterEvent` 只接受 `hasUrls()` 的拖入；`dropEvent` 按当前页分派，压缩页逐个去重入列，解压页取第一个路径并要求 `.sy` 后缀（`SFC_GUI/src/MainWindow.cpp:113-143`）。目录以单条路径入列，展开与扫描在归档写入阶段完成（`SFC_GUI/src/CompressionWorker.cpp:215-216`）。

## 10. 国际化

语言文件 `SFC_GUI/translations/SimpleFilesCompressorGUI_zh_CN.ts` 编译为同名 `.qm`，由 `SFC_COPY_EXTERNAL_TRANSLATIONS` 控制复制到 exe 同级 `translations/`（`BuildTest/CMakeLists.txt:205-216`），同时以 `:/i18n/` 前缀内嵌（`SFC_GUI/resources.qrc:6-8`）。`main.cpp` 从 `SFC_GUI_LANGUAGE` 或系统 UI 语言生成候选，仅在首选语言为中文时逐个以 `translator.load(fileBaseName, QDir(QCoreApplication::applicationDirPath()).filePath("translations"))` 加载，失败回退 `:/i18n/` 下的同名 `.qm` 资源，成功后 `installTranslator`（`SFC_GUI/src/main.cpp:108-125`）。字符串标记：界面串一律 `tr()`；`CompressionWorker` 的进度状态与检查点处的取消结果用 `tr()`，成功、失败与主循环异常路径的取消结果用英文 `QStringLiteral` 原样发出，再由 `localizeWorkerDialogMessage()` 按前缀匹配后经 `QCoreApplication::translate("CompressionWorker", ...)` 输出。

## 11. 关闭时的析构顺序

1. `requestStop()` 置位取消标记，取消链路见 §6 第 1 步。
2. `m_workerThread->wait(3000)`；超时则 `terminate()` 再 `wait()`，随后 `delete` 线程（`SFC_GUI/src/MainWindow.cpp:27-34`）。
3. `delete m_worker`（`:36-39`）。

线程退出前不得 `delete m_worker`，此时工作对象仍在工作线程上执行 `doCompression()` 或 `doDecompression()`；`terminate()` 是 `wait(3000)` 超时后唯一的强制手段。

## 12. 改动影响面

- 两页各有一套独立控件；新增任务状态量时，压缩页与解压页的 `finished` 槽都要复位。
- 取消入口接到界面时只准调 `requestStop()`，不得直接 `delete` 工作对象或 `quit()` 线程。
- 改动 `CompressionWorker` 的信号签名，须同步两个 `MainWindow` 槽声明与 `.ts` 中的 `CompressionWorker` 上下文。
